# ICT261 Reflection

This project demonstrates a maintainable Java desktop application. The JavaFX view is separated from controller code with FXML. StudentService owns validation and duplicate-number rules, while the repository owns database operations. ObservableList and TableView keep the UI synchronized with student data. H2 provides embedded persistence, and JUnit tests verify important service rules.

The project follows the course principle of moving from “it runs” to “it is maintainable”.
